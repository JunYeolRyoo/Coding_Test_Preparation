``` python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        res = 0
        charDic = {}
        left = 0

        for i in range(len(s)):
            if s[i] in charDic and charDic[s[i]] >= left:
                left = charDic[s[i]] + 1
            else:
                res = max(res, i-left+1)
            charDic[s[i]] = i
        
        return res
```

***Time Complexity: O(N)<br>***
***Space Complexity: O(k) (where k is number of distinct character)***
